视频下载器

小伊的工具箱 · 只在本机运行的 Windows 视频下载工具。粘贴链接、选保存位置，就能看进度并下载。

下载 Windows 启动包 发布记录与校验值 查看源码仓库

启动包约 100 KB（源码 + 启动脚本），首次运行再联网准备约 135 MB 运行组件。不包含离线组件，也不需要安装 Node.js、FFmpeg 或 Python。

SHA-256：01f630f0d75383cd0dee1698efc3cea9752d0e337732d4607cf70d3c35eb355b

快速开始

  1. 下载启动包，右键「全部解压」，不要直接在压缩包里运行。
  2. 打开解压后的 video-downloader 文件夹，双击 视频下载器-Windows.bat。
  3. 首次启动会联网准备并校验组件，随后自动打开浏览器。
  4. 不用时双击 停止视频下载器-Windows.bat；只关浏览器标签页不会停止后台服务。

支持范围

网站抖音、小红书、B站、YouTube、央视频，以及 yt-dlp 能解析的站点
直链MP4 / M3U8 / MPD 地址
系统Windows 10 / 11，64 位（macOS、Linux、ARM64 暂无发布包）
隐私服务只监听 127.0.0.1，不上传链接、账号或下载的文件

不保证每个链接都成功；付费、登录、DRM 内容不会被绕过。在中国大陆访问 YouTube 通常需要可用的网络代理。
